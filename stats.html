Counter

Everything the site knows about its own traffic. These are counts only — a date, a name and an integer. No visitor is identified, and there is no third-party analytics anywhere in this build.

Reading the counters…

Page views count a page opening in a browser. Bots that execute JavaScript are included; there is no filtering.

Download starts count presses on the APK button. A website cannot see whether an install finished, so this is a floor, not an install count.

Account count is not published here. The number of registered people is business data, and this endpoint answers to any browser, so it is read locally with the service key instead.

Nothing here is tamper-proof: the counting endpoint is public by necessity, so someone could inflate a number. Treat these as a smoke signal rather than a measurement.
